已验证的 Gloo 规避配置：

```bash
export GLOO_SOCKET_IFNAME=enp39s0f0
export HCCL_SOCKET_IFNAME=enp35s0f2
export IP_SOCKET_IFNAME=enp35s0f2
# 25 节点为 177.11.25.1，26 节点为 177.11.26.1
```

此前 Gloo 在 `enp35s0f2` 上发生过可由纯 CPU 测试复现的数据异常，切换接口后通过 CPU 对照和模型回归。结论限定为该通信路径的实测差异，未证明具体网卡驱动内部根因；没有修改宿主机网络配置。详细证据见 `/workspace/experiments/gloo_communication_diagnosis_20261112.md`。
